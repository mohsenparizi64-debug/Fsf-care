# Fsf-care

وب‌اپ فارسی موبایل‌فرندلی برای سنجش تغییرات حجم و جهت رشد یک جسم
از روی مقایسه دو عکس با **زاویه ثابت**.

## ساختار پروژه

```text
fsf-care/
├── backend/
│   ├── app/
│   │   ├── __init__.py
│   │   ├── main.py        # FastAPI: سرو صفحه + API (۳۳ مسیر)
│   │   ├── auth.py        # احراز هویت توکنی + ماتریس ۹ سطح دسترسی
│   │   ├── projects.py    # پروژه‌ها، عکس‌ها، نظرات، تاریخ شمسی
│   │   ├── pipeline.py    # بینایی ماشین: تراز (ECC)، سگمنتیشن (GrabCut)، سنجش
│   │   └── pdfgen.py      # گزارش PDF فارسی RTL
│   ├── requirements.txt
│   └── server.bat         # اجرای ساده روی ویندوز
├── frontend/
│   └── index.html         # تک‌صفحه فارسی RTL، موبایل‌فرندلی
├── Dockerfile
└── run.bat
```

## اجرا

### لوکال (ویندوز)
```bat
cd backend
pip install -r requirements.txt
run_server.bat
```
سپس مرورگر را روی `http://127.0.0.1:8092` باز کنید.

### Docker
```bash
docker build -t fsf-care .
docker run -p 8092:8092 -v fsf_data:/app/backend fsf-care
```

## امکانات

- **دوربین تمام‌صفحه** درون برنامه با ابزارهای حرفه‌ای: گرید، زوم نوری/دیجیتال،
  فوکوس دستی، EV، ISO، تراز سفیدی، چراغ قوه، حالت‌های صحنه
- **شبه‌عکس (ghost)** برای تطبیق زاویه: عکس قبلی روی تصویر زنده نمایش داده می‌شود
  با کادر زرد راهنما — قاب ۳:۴ ثابت، آنچه می‌بینی همان چیزی است که ثبت می‌شود
- **تاریخ شمسی**: روز هفته + تاریخ جلالی + ساعت ۲۴ ساعته روی هر عکس
- **احراز هویت**: توکن Bearer، ۹ سطح دسترسی، فقط ادمین می‌تواند کاربر بسازد
- **گزارش PDF** فارسی RTL با اندازه‌گذاری و جهت رشد
- **نظرات و تأیید** عکس‌ها توسط ناظر فنی

## نکات امنیتی

- فایل `backend/auth/users.json` شامل هش پسوردها است و در گیت نیست (`.gitignore`)
- عکس‌های کاربران در `backend/projects/` هستند و پوش نمی‌شوند
- ادمین پیش‌فرض هنگام اولین اجرا ساخته می‌شود — **رمز را تغییر دهید**
